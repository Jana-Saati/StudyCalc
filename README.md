# StudyCalc

A smart academic web platform that helps university students manage their
academic life, built as a project for the Web Data Analysis course at
Umm Al-Qura University, 2026.

🔗 **Live website:** https://studycalc.pythonanywhere.com

## ✨ Features
- **GPA Calculator**
- **Budget Planner** for monthly expenses
- **Study Schedule Generator**
- **Dashboard** with a gamification points system
- **Student Quiz** for personalized study-type insights
- **Accounts** with a profile page and an admin dashboard

## 📊 Website Performance Analytics
After launch, we analyzed the traffic with Google Analytics
(April 27 – May 24, 2026).

| Metric | Result |
|---|---|
| Active users | 351 |
| Sessions | 542 |
| Mobile users | 88.43% |
| Direct traffic | 85.06% |

**Key insights**
- Most visitors came from direct links shared on WhatsApp and social media,
  so peer-to-peer sharing was the most effective acquisition channel.
- New users rose from 40 to 311 between the two halves of the period.
- The GPA Calculator was the most engaging tool (bounce rate 6.31%).
- The `/study` page had an 80% bounce rate on mobile, so it needs a
  mobile experience fix.
- The `/contact` page had a high bounce rate on all devices.

**Suggested next steps:** improve the mobile experience, encourage repeat
visits and account creation, and improve SEO.
